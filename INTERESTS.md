# Interests

## Audience

Senior front-end engineer. Skip beginner explanations; focus on what changed, why, and trade-offs.

## Topics (highest priority first)

- Vue / Nuxt releases, RFCs, and ecosystem tooling
- React / Next.js releases and rendering model changes (RSC, SSR, streaming)
- Web platform: new browser APIs, CSS features, Baseline status changes
- Build tooling: Vite, Rolldown, bundlers, TypeScript
- Web performance and Core Web Vitals
- AI-assisted development tooling

## Pro tips (used when there's no substantive news)

- Nuxt: data fetching (useFetch/useAsyncData keys, caching, dedupe), rendering modes and route rules,
  Nitro server routes and caching, modules and layers, Nuxt Content queries, SEO/meta utilities, performance
- Next.js: App Router patterns, Server Components vs Client Components boundaries, caching and revalidation,
  Server Actions, middleware, metadata API, image/font optimization, performance
- Prefer tips that fix a common mistake or a real performance/DX problem, with before/after code

## Preferred sources

- Official blogs and changelogs (vuejs.org, nuxt.com, react.dev, nextjs.org, web.dev, developer.chrome.com)
- Official docs (nuxt.com/docs, nextjs.org/docs) for verifying pro tips
- GitHub releases of the relevant projects
- MDN, TC39 proposals, W3C/WHATWG

## Avoid

- Listicles, SEO content farms, "top 10" posts
- Pure hype or funding news with no technical content

## Tone

Direct, technical, no filler. Code examples over prose where possible.
